# Installing Vetto

Vetto is distributed as a single static native binary across Linux, macOS, and Windows.

---

## 1. Package Managers

### npm (cross-platform global binary)

```bash
npm install -g @shledery/vetto
```

The npm package contains pre-compiled native binaries for Linux (x64/arm64), macOS (x64/arm64), and Windows (x64). It executes without building from source or making network requests during install.

### Homebrew (macOS & Linux)

```bash
brew install shleder/tap/vetto
```

### Cargo (crates.io)

```bash
cargo install vetto
```

---

## 2. Standalone Installer (Linux & macOS)

Install the latest pre-compiled `vetto` binary to `~/.local/bin` using `curl`:

```bash
curl -fsSL https://raw.githubusercontent.com/shleder/vetto/main/install.sh | bash
```

### Options

Install system-wide to `/usr/local/bin`:

```bash
curl -fsSL https://raw.githubusercontent.com/shleder/vetto/main/install.sh | bash -s -- --system
```

Install to a custom directory:

```bash
curl -fsSL https://raw.githubusercontent.com/shleder/vetto/main/install.sh | bash -s -- --dir /custom/bin
```

---

## 3. GitHub Releases & Direct Binary Download

Pre-built release archives, cryptographic checksums (`checksums.txt`), and Minisign signatures (`.minisig`) are published on [GitHub Releases](https://github.com/shleder/vetto/releases).

Every release binary includes SLSA Level 3 build provenance generated by Sigstore and GitHub Actions.

---

## 4. Verification

After installation, verify that Vetto is working and check host kernel capabilities:

```bash
vetto --version
vetto doctor --preflight
```
